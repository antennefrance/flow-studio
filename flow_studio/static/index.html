FLOW (Fast Lossless Offloaded Weights) は、RAMとNVMeを階層分離し、低スペックPC上で巨大モデルを高速・安定稼働させるストリーミング推論システムです。

2つのストリーミング・モードに対応:
・⚡ FLOW-Direct: 既存の標準モデル（.gguf / .safetensors）を変換不要・そのまま即座にロード。リングバッファDMAにより RAM 2.5GB〜3.5GB 固定枠で 141B MoE 等が OOM ゼロで動作。
・🚀 FLOW-Boost: 可逆圧縮（.flow）により、PCIe/NVMe 物理転送帯域を 2.4倍にブースト。
